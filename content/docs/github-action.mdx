> This is an example workflow built on the scripts, not a published Action. Test it on your repository before relying on it.

It scans, plans and replays your fixtures, then adds the report to the job summary. It does not push or open a pull request. A parity failure fails the job.

```yaml
name: breakline
on:
  schedule: [{cron: "17 3 * * 1"}]
  workflow_dispatch: {}

permissions:
  contents: read

jobs:
  check:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Get Breakline
        run: |
          git clone --depth 1 https://github.com/aorta-labs/breakline "$RUNNER_TEMP/breakline"
          python3 -m pip install pyyaml
      - name: Scan, plan and check parity
        env:
          OPENAI_API_KEY: ${{ secrets.OPENAI_API_KEY }}
          ANTHROPIC_API_KEY: ${{ secrets.ANTHROPIC_API_KEY }}
        run: |
          S="$RUNNER_TEMP/breakline/breakline/scripts"
          python3 "$S/scan.py" .
          python3 "$S/plan_patch.py" .
          python3 "$S/parity.py" . --live
      - name: Report
        if: always()
        run: |
          python3 "$RUNNER_TEMP/breakline/breakline/scripts/report.py" . || true
          cat .breakline/out/pr_body.md >> "$GITHUB_STEP_SUMMARY" || true
```
