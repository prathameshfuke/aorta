---
title: "Scripts"
description: "The five scripts, their flags and exit codes."
---

Run them with `python3`, from any directory. Each prints JSON on stdout and text on stderr.

| Script | What it does |
| --- | --- |
| `scan.py <repo>` | Lists retiring calls, soonest deadline first |
| `verify_dates.py` | Lists registry dates still marked unverified |
| `plan_patch.py <repo>` | Writes the diff. Changes source files only with `--apply` |
| `parity.py <repo>` | Replays fixtures. Needs `--live` or `--simulated` |
| `report.py <repo>` | Writes `pr_body.md` |

## Flags

| Flag | Script | Effect |
| --- | --- | --- |
| `--replace OLD=NEW` | `plan_patch.py` | Choose a replacement for one run |
| `--apply` | `plan_patch.py` | Write the `allow` sites |
| `--include-ask` | `plan_patch.py` | With `--apply`, also write the `ask` sites |
| `--live` | `parity.py` | Call the real models |
| `--simulated` | `parity.py` | Offline demo. No model is called and it proves nothing |
| `--registry <file>` | all | Use your own change registry |
| `--today <date>` | all | Override the date |

Run any script with `--help` for the rest.

## Exit codes

| Code | Meaning |
| --- | --- |
| `0` | Completed |
| `2` | Parity failed: keep the pull request in draft |
| `3` | Configuration error. The message says what to fix |
