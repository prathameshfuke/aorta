> Breakline is in early development. Commands and file formats may change.

Using Claude? [Install the skill](/docs/skill) and ask it. These are the same steps by hand. You need Python 3.10 or newer.

## 1. Get it

```bash
git clone https://github.com/aorta-labs/breakline
python3 -m pip install pyyaml
```

## 2. Scan

The scanner reads files and changes nothing.

```bash
python3 breakline/breakline/scripts/scan.py path/to/repo
```

Each finding shows the file, line, model or API, effective date and days left.

## 3. Choose replacements

Add `.breakline/policy.yaml` to your repository and map each retiring model to the one you want to test.

```yaml
replacements:
  gpt-4o-2024-08-06: gpt-5.4-mini
rules:
  - match: {path: "*"}
    action: allow
```

## 4. Plan

This writes `patch.diff` and `result.json` under `.breakline/out/`. No source file changes.

```bash
python3 breakline/breakline/scripts/plan_patch.py path/to/repo
```

## 5. Prove

Save real prompts and the outputs you rely on as [fixtures](/docs/fixtures), add [prices](/docs/prices), then replay them. Live parity spends tokens on your account.

```bash
export OPENAI_API_KEY=...
python3 breakline/breakline/scripts/parity.py path/to/repo --live
```

## 6. Apply and report

Read the diff first. Then write the `allow` sites and the report.

```bash
python3 breakline/breakline/scripts/plan_patch.py path/to/repo --apply
python3 breakline/breakline/scripts/report.py path/to/repo
```
